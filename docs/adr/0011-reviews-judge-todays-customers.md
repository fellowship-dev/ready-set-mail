# Reviews judge what can happen with today's customers

A review finding must name a way it can happen with the installations and customers that exist today. Hypothetical legacy states with no real holder are not fixed or reviewed further. Owner, 2026-11-15, on a finding about "old" parent-domain verifications: "What old domain? We have no customers."

**Consequences**
- A finding with no path through a real installation is closed with that reason, not patched.
